What it reads

Keywords tab

Header row with Keyword Theme, Keyword, Landing Page, Ad Message. An optional Match Type column overrides the blanket split for that keyword.

Responsive Search Ads tab

One headline per row under Campaign Theme, with pin columns and a display URL.

Ad Extensions tab

Blocks found by the header cells Sitelink Text, Callout Text, Structured Snippets Headers. A mark in the far-left column pre-selects the row.

Red fill means not MLR approved. Any cell filled red is read as having failed medical, legal and regulatory review and excluded by default — a red keyword row drops the keyword, a red headline or description cell drops that line, a red extension row drops the extension. You can review and override every one of them.
